Electrically Programmable Beam Steering in a Strong-Coupling Hybrid-2D Excitonic Metasurface

## Slide 1: Main Paper A

**Message:** MoSe2 excitonic metasurfaces already show that 2D excitons can steer reflected beams.

- Main paper: excitonic beam steering in an active vdW metasurface.
- Existing capability: tune reflection amplitude, phase, wavefront, and propagation direction.
- Limitation: bare-exciton phase tuning can be accompanied by amplitude loss.

## Slide 2: New Method B

**Message:** Gate-tunable strong coupling offers a better control mechanism.

- Hybrid-2D excitonic metasurfaces support exciton-photon strong coupling.
- Gate voltage changes carrier density and exciton linewidth.
- Strong/weak coupling changes the complex reflection coefficient.

## Slide 3: Our Innovation C

**Message:** Turn the original bare-exciton phased array into a gate-tunable exciton-polariton phased array.

- Each metapixel has a gate-controlled complex reflection coefficient.
- A target steering angle is converted into a phase gradient.
- The phase gradient is converted into a gate-voltage profile.
