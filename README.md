# OPCTICAL-CHANGE

This repository contains low-dimensional-material proposal projects organized as self-contained folders.

## Projects

- [`test-0/`](test-0/) - Gate-programmable complex SHG zeros and phase winding in bilayer WSe2.
- [`test1/`](test1/) - 基于电控强耦合 MoSe2/WS2 激子超表面的可编程光束偏转实验设计.

The `test1/` topic was selected over SHG/qBIC backup ideas because it gives the clearest design-prediction-control-measurement loop and is directly testable with deterministic Python simulations.
